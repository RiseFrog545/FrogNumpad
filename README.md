# FrogNumpad
19-key numpad section of a keyboard 

Standard 17 Keys, 2 Macro Keys 

![Full Numpad](https://github.com/user-attachments/assets/13391622-a548-4337-8c27-fca6d03d647c)

<br>
The Numpad has an indicator light for when Num Lock is active. <br> 

(https://github.com/user-attachments/assets/402f14e3-4c8d-4292-85e3-ebc5f5f5098b)
<br>
Here's a video <br> 

I designed the PCB in KiCad.
Parts were 3D printed from files I designed using AutoDesk Inventor. <br> 

I was looking for something to make to give myself a little bit of familiarity with PCB design, so I decided to make a numpad. <br>

The keyboards firmware is on a Elite-PI RP2040 Microcontroller, made using QMK Keyboard Firmware. <br>
